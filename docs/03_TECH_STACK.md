# 03 - Tech Stack

## 1. Frontend (Web MVP)
*   **Framework:** Next.js + React (Fast to build, easy to demo on any device without app store friction).
*   **Styling:** Tailwind CSS.
*   **Animation:** Framer Motion (for cinematic transitions and train/boat/helicopter movement).
*   **Map Integration:** React Simple Maps (SVG/TopoJSON based) for the interactive India map.
*   **Genome Visualization:** React Flow (for the connected-node graph - fast to build).
*   **Native/AR Layer:** Planned as a stretch goal/roadmap, not MVP.

## 2. Backend, Database & Storage
*   **Platform:** Supabase (Postgres DB, Auth, and File Storage all in one, minimal boilerplate).
*   **Media Hosting:** Supabase Storage, Cloudinary, or Firebase Storage (for pre-recorded Guru Connect video clips).

## 3. Integrations & AI
*   **Payments (Marketplace POC):** Razorpay (ideal for an India-focused product with local artisans/farmers).
*   **AI Guide/Chatbot:** Gemini or Groq (for a lightweight Q&A assistant layered on top).

## 4. Deployment
*   **Frontend Hosting:** Vercel.
